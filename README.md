# perros_tio
Sistema de Stock y Ganancias - Puesto de Comida Rápida
Sistema web para gestionar el inventario, las ventas, las compras y las ganancias de un puesto de comida rápida de perros calientes

¿Qué es?

Una aplicación hecha con Django que permite al dueño del puesto:
- Registrar ventas y descontar insumos automáticamente.
